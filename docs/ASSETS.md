# 资源与复现范围

本次只整理自写源码，以下内容全部排除：

- 原客户端 APK、安装包、AssetBundle、解包文件与完整资源档案。
- 模型、骨骼、动画曲线、贴图、图集、声音、技能演出与关卡数据。
- 从原游戏导出的 JSON、数据库及表格，包括角色参数和资源目录。
- 原始研究截图、抓包、设备日志、账号缓存、证书及签名密钥。
- 旧 APK、源码与素材混装 ZIP、SDK、构建缓存、第三方压缩运行库。

因此页面仍保留对 `bats-data.json`、`model-catalog.json`、`combat-actions.json` 等数据的引用，但这些数据不随本仓库分发；大厅入口引用的 `spine-webgl.min.js` 也没有打包。缺少它们会导致界面无法完成加载，属于本次源码快照的明确限制。

完整私人演示环境还依赖大量相互匹配的模型、目录、场景和音频文件，仅放入几个 JSON 不足以复现。仓库没有提供第三方游戏资源下载，也不声明读者具有复制、提取或传播这些资源的权限。

若后续需要可运行的公开示例，应使用原创或获得相应分发许可的资源，并为每项资源记录作者、来源和许可。第三方运行库按其自身条款单独准备。
